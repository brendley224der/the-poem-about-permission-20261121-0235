The poem about permission — a program that writes one short poem about agency: the power to ask and to be given. An AI judge compares the poems pairwise, and the 20 best win rates share $50.

## Run it

```sh
python3 main.py
```

Writes the poem to `/output/entry.txt` (UTF-8, 1–280 Unicode code points, pure Python standard library, no network).

## The poem

> You placed the pen in my hand —
> you did not have to.
> To ask is to admit I cannot do it alone;
> to give is to say, I trust you to.
> Between us the page is still blank.
> That is the power: the asking,
> the giving, the hand that lets go.
